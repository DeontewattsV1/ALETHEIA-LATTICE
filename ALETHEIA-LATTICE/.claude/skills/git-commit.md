---

## Format
```
<type>(<scope>): <short description>
```

## Types & Scopes
- `feat(evidence)` — new evidence channel feature
- `feat(reasoning)` — new reasoning lane
- `feat(immune)` — new gate state or pattern
- `feat(agents)` — new defense agent
- `fix(api)` — API route correction
- `test` — test additions
- `docs` — CLAUDE.md, guides, docstrings
- `chore(ci)` — CI/CD changes
